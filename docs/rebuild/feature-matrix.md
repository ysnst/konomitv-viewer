## 受け入れ条件とテストの引き継ぎ

0.33の19項目中18件成功のうち、キャプチャ2項目は新構築の必須条件から外し、残る16項目を回帰条件とする。生放送と連続切り替えは追加の重点条件。[実機記録](../testing/device-0.33.md)は改変せず保持する。保存先がサーバー以外の写真/両方、H.264、生放送PiP等の未確認結果を成功へ転記しない。

旧Python9件は成果物検証用として再利用し、段階0では来歴用3件を加えた12件を実施する。旧Swift群は採用する状態モデルに必要なものだけを再利用し、キャプチャ群は除外する。VLC4のseek完了APIをそのまま移植しない。段階0には本家に存在しないモデルをテストのためだけに追加しない。旧HTTP7件はHLS/relay等の契約を本家構造に合わせて適用し、生放送・認証・切り替えのfixtureを別途拡張する。既存成功を新構築の成功として流用しない。

## 現在のゲート

段階0は実機合格。段階1/2は本家を維持して[残存条件を検証中](stage-1-2.md)。相互切り替えと読み込み中の離脱はユーザー回答でも未確認のため、段階5の本実装へは進んでいない。段階3/4を迂回することを、段階1/2の未確認条件を合格にする理由にはしない。
