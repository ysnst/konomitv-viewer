## 受け入れ条件とテストの引き継ぎ

0.33の19項目中18件成功のうち、キャプチャ2項目は新構築の必須条件から外し、残る16項目を回帰条件とする。生放送と連続切り替えは追加の重点条件。[実機記録](../testing/device-0.33.md)は改変せず保持する。保存先がサーバー以外の写真/両方、H.264、生放送PiP等の未確認結果を成功へ転記しない。

旧Python9件は成果物検証用として再利用し、段階0では来歴用3件を加えた12件を実施する。旧Swift7群は対応する状態モデルを採用する段階で再利用する。段階0には本家に存在しないモデルをテストのためだけに追加しない。キャプチャ群は除外。旧HTTP7件はHLS/relay等の契約を本家構造に合わせて適用し、生放送・認証・切り替えのfixtureを別途拡張する。既存成功を新構築の成功として流用しない。
