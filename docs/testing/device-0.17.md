ONは先頭番組へ合わせるためヘッダー・見出し・上部ページネーションが隠れる。OFFは下部ページネーションからのページ変更で表示位置が上がり、ページ送りを続けにくい。

フェーズFではONを一覧画面全体の最上部、OFFを操作元ページネーションの画面内位置保持へ変更する。7ボタンへ戻し、撮影を映像内へ移す。情報/コメントタブは最下部固定、設定は映像下の固定領域、履歴保持件数は確定時だけ保存する数値入力へ変更する。

PiP内字幕・実況は今回の対象外。フェーズEの判断と正常なPiP経路を維持する。この記録はフェーズFの実機成功を意味しない。
