# フェーズAの実機確認項目

IPA 0.6の実機成功記録は device-0.6.md。今回の変更は別のIPAであり、ソースレビュー/ビルドと端末確認を区別する。

- ページ送りON/OFF、直接ページ指定、短いページ、通信失敗、連打。
- ホームから一覧を新しく開くとページ1/先頭/一時条件なし。タブ・再生から戻ると元のページ/検索/フィルタ/並び/位置。
- 字幕・設定・全画面が映像内にあり、未対応のキャプチャ/PiPのダミーがない。
- 全画面中の字幕ON/OFF、コメントON/OFF、再ONとシーク後の同期。
- 通常/全画面の設定値一致、画質・プロファイル・速度・音声のみ・タイマー・ダイジェスト。
- 設定サブメニューから閉じる/スワイプでも再生が止まらず、操作の自動非表示が再開。
- 縦/横/狭い幅/表示倍率、Safe Area/ステータスバー/長い題名/時計/戻る操作。
- 中央再生・10秒戻し・30秒送り・区間移動・番組前後移動・密度グラフ・シーク区間・番組情報/コメントタブ。
- 0.6成功済みの9項目、字幕/データ放送、生放送、回転/品質変更。H.264は実機対象外、ソース/ビルドで維持する。

WindowsではUIKitの実画面を起動・撮影できないため、これらを成功扱いしない。
