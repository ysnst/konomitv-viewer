# 録画の全画面コメント確認

## 修正範囲

録画 H.264（AVPlayer）と録画 HEVC（MobileVLCKit）の全画面表示へ、通常画面で使っている実況コメントビューを貸し出す。全画面解除時は借用中の制約を解除し、通常画面の映像・字幕より上、操作帯より下へ返す。

コメントの取得、再生時刻の供給元、表示設定、NG 条件による除外、プレイヤー、認証、履歴同期は既存処理を使う。生放送側の借用・返却処理を参考にしているが、生放送のコードは変更しない。

## 自動・静的検証の範囲

- `Build (unsigned IPA)` で CocoaPods を導入し、iOS 向け Release ビルドを行う。
- `scripts/test_verify_ipa.py` は生成物の照合処理を検証する。実況表示や動画再生のテストではない。
- `scripts/verify-ipa.py` は IPA の SHA-256、期待する完全なコミット SHA、アプリ内 JSON、Info.plist、実行ファイルの存在を照合する。
- コードレビューでは両経路の借用・返却、制約の解除・再有効化、重なり順、コメントインスタンスと時計の継続、変更範囲を確認する。

これらの成功だけでは iPhone/iPad 上の動作を確認したことにはならない。

## 実機確認

### IPA 0.4 のユーザーによる確認結果

対象コミットは `81fc3391439d0ddc8e1b057f41ce2f790c709202`。2026-11-25 にユーザーから報告された結果であり、開発環境で実行したテストとは区別する。

- 端末: iPhone 17 Pro。iOS の詳細バージョンは未報告。
- 導入方法: LiveContainer。
- 接続: Cloudflare Access サービストークン認証。
- 録画: Amatsukaze で HEVC にエンコード。本家 KonomiTV PWA を併用。

| シーク後のコメント同期 | 成功（ユーザー確認） |
| Cloudflare Access 経由の再生 | 成功（ユーザー確認） |

H.264 の実機テスト用動画の用意や再エンコードは行わない。H.264 の既存対応は維持し、コードレビューとビルドによる検証を続ける。上記結果を将来の IPA の実機確認済み結果として扱わない。
