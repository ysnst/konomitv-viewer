# フェーズDの検証と実機チェックリスト

IPA0.16のユーザー報告は[device-0.16.md](device-0.16.md)。本書は後続実装の確認範囲を示す。WindowsではUIKit・iOS・LiveContainerを起動できないため、新しい画面のスクリーンショットと実機動作は未確認。ビルド・テスト・IPAの照合結果はartifactsの詳細報告へ記録する。

## ソースと独立レビュー

- ページ送りのONは先頭番組行の実座標、OFFは操作直前のoffsetとインセット差を使う。現在ページだけセル高を測り、推定行高の後続補正を避ける。更新は反映直前の位置を使う。失敗時はデータ・ページ・位置を変更しない。
- 測定セルの仮高さ0、音声のみ解除後の実況ボタン無効化、生放送キャプチャのevent_id欠落を独立レビューで指摘し、修正を再確認した。
- 5ボタンは実況・字幕・設定・PiP・全画面。通常/全画面で所有元の状態を共有し、撮影2種は設定へ移した。再起動は最下部。
- シークは4ptトラック、11ptつまみ、映像内32ptの操作領域。CM帯もトラック高へ合わせる。密度は26ptの非操作オーバーレイで、タッチ開始から終了/取消までだけ表示し、レイアウトの高さを変更しない。
- キャプチャのフレーム取得は既存経路を維持。画像処理・JPEG/EXIF・multipart構築を背景へ分け、AV出力はフレーム取得後に外す。一要求ずつ保存し、接続先を各アップロード前に照合する。

## 自動検証

- 既存Python9件はIPA来歴検証器のテストであり、UIKitの動作試験ではない。
- 既存HistoryStoreTests.swiftは実ストアの進捗計算と制御通信による競合を検証する。
- 新規CaptureMetadataTests.swiftは本番CaptureJPEGへ実JPEGを渡し、独立TIFF readerで日本語・絵文字・null・識別子・合成フラグ・日時を読む。元JPEG部分の保持、ImageIOによる復号、無効JPEG・容量超過を確認する。CI成果物のcapture-metadata-test.jpgはサーバーと同じPillowで別途読める。
- actionlintとiOS Releaseビルドを行い、IPA内外来歴・完全SHA・SHA-256・version/buildを照合する。0.16の87警告を比較基準とする。

## 実機未確認項目

以下はすべてフェーズDの実機未確認。0.16の成功項目を新しい版の成功へ転記しない。

| 範囲 | 実機で確認する操作・期待値 |
| --- | --- |
| スクロールON | 次/前/番号指定で先頭番組へ移動し、検索欄等まで上がりすぎない |
| スクロールOFF | 同じ範囲なら上下移動なし、短い最終ページだけ有効範囲へ補正 |
| 通信 | 失敗時に現在ページ・位置保持、連打で古い結果が上書きしない |
| 更新/復帰 | 30秒更新・進捗/画像更新・タブ/再生/背景からの復帰で位置と条件を保持 |
| 新規一覧 | ホームのもっと見るからは毎回ページ1・先頭・一時条件なし。OFFでも同じ |
| 大量録画 | 検索/ページ送りの応答、セル表示、測定中のUI負荷 |
| 5ボタン | 通常/全画面の順序、ON/OFFのアイコン・実表示一致、音声のみ解除後の再操作 |
| 設定 | 現在値/字幕/実況状態の共有、メニュー閉鎖、設定中の再生継続 |
| 撮影操作 | 設定から通常/実況付き撮影、字幕保存3モード、再起動が最下部 |
| 写真のみ | 許可/拒否、元解像度、ファイル名・JPEG・コメント/字幕、操作UI写り込みなし |
| サーバーのみ | 写真権限を要求しない、CF Access経由保存、サーバー側表示・番組関連付け |
| 両方 | 保存先別の成功/失敗通知、片方失敗時に他方を正しく処理 |
| 保存中 | 再生継続、二重撮影防止、シーク/画質/PiP/接続先変更、不要な一時ファイルなし |
| 保存設定 | 再起動後保持、PWAとの設定同期、既存設定の保持 |
| シーク | タップ/ドラッグ/取消、細いトラック/つまみ、CM帯、再生時刻と字幕/実況同期 |
| 密度 | タッチ中だけ表示、終了/取消で消える。グラフとシークの横座標一致、位置・映像サイズ不変 |
| 非表示 | 通常再生/停止/他ボタンではグラフなし、シーク中/設定中に意図せず操作が消えない |
| レイアウト | 縦/横・長い時間/題名・回転、Safe Area/ホームインジケーター、情報領域とタップ競合 |
| 既存機能 | HEVC映像/音声、中央5操作、全画面コメント、データ放送、予約/マイリスト等 |
| PiP回帰 | HEVC開始/背景継続/復帰/位置同期、シーク/速度/ON-OFF状態保持 |
| LiveContainer | 直接PhotoKit保存のホスト権限、ステータスバー、バックグラウンド/復帰 |
| 性能 | 長時間のCPU/GPU/メモリ・発熱・消費電力、4K撮影時ピーク |

生放送PiPは実機未確認。H.264素材の新規準備は対象外で、既存経路はコードレビューとビルドで検証する。PiP内字幕・実況は未実装で、詳細は[pip-investigation.md](../pip-investigation.md)のフェーズE判断を参照する。
