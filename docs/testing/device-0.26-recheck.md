## 確認された不具合

1. 生放送の映像tapで再生が停止する。
2. 録画のバーtap後、場面プレビューとコメント密度が表示されたままになる。

シーク後の字幕同期は今回成功したが、過去の同期ずれの原因が特定されたわけではない。0.33のlive再生失敗は今回0.26では再現しなかったが、0.33の原因を解明したとはしない。

キャプチャ除去・5ボタン化は撤回済み。0.26の通常/字幕付き撮影、各保存先/設定/権限/JPEG・EXIFと6ボタンを維持する。ただし今回キャプチャの個別成功は追加報告されていない。写真/両方保存等を成功へ昇格しない。H.264、BMLや他認証、未実施の寿命組合せも実装と実機結果を区別する。

## 残る一覧復帰の確認

1. ホームのもっと見る→5ページなどへ移動→途中までscroll。
2. 別タブ→録画タブへ戻り、page/位置/検索/絞込/並び順を確認。
3. 一覧途中の録画を再生して戻り、同じ状態を確認。

不具合が確認されるまでは一覧を再実装しない。未視聴/保護filterの最大50page/1500件走査は既存制約として維持する。
