## 別件: シーク後の字幕同期ずれ

追加検証の報告は「きっかけはわからないが若干字幕がずれた。再生しなおすと直った」、続いて「シークしたときですね」。字幕の表示自体と残留防止は機能するが、シーク後に映像/音声との表示タイミングが若干ずれる場合があり、再生し直すと戻る。これをフェーズHの残存不具合として、上の16項目および過去の残留不具合とは別に扱う。

早い/遅いの方向、秒数、一定/拡大/自然復旧、頻度、前方/後方、操作種別、距離、再生済み/未知区間、停止中、バッファ、全画面/PiPとの関係、G起因か以前からか、正確な再現条件はいずれも不明。推測で補わない。

「接続と保存」の成功を写真ライブラリ/両方保存の個別成功へ読み替えない。これら2方式は個別実機成功報告がなく未確認を維持する。新版の実機結果もこの記録から転記しない。

IPA 0.20を実機検証済み基準版として維持する。追加情報が得られるまで同期ずれの修正は保留し、[調査報告](../subtitle-sync-investigation.md)と[再発時の確認事項](phase-h.md)を参照する。
