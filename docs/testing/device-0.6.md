# IPA 0.6 のユーザー実機検証

対象: `6a1e698e19fed90e75f80d0982df5ff5ed83507e`、IPA 0.6 / build 6。以下はユーザーから報告された結果で、開発環境で再現した結果ではない。

環境: iPhone 17 Pro、LiveContainer、Cloudflare Accessサービストークン認証。本家PWA併用。Amatsukaze HEVC録画を数千件以上保存。H.264録画は存在しない。

| 確認項目 | 結果 |
| --- | --- |
| 録画ホームの新着10件・マイリスト4件・履歴4件 | 成功 |
| 検索・もっと見る | 成功 |
| PWAの視聴位置がViewerの進捗バーに表示 | 成功 |
| Viewerの位置変更がPWAへ反映 | 成功 |
| 30秒更新後のスクロール保持 | 成功 |
| 大量録画の一覧・検索・ページ送り | 成功 |
| HEVC再生・全画面コメント | 成功 |
| Cloudflare Access経由の再生 | 成功 |
| 0.4からの接続先・認証・設定保持 | 成功 |

改善点: 全画面で字幕・コメントを操作できない、全画面操作が映像外、PiPなし、明示ページ送り後の位置と新規一覧の状態持越し、黒いステータスバー文字、大型ヘッダーと分散した設定。

これ以降のIPAの実機結果とは区別する。H.264の素材作成・再エンコードは行わず、既存対応のソースレビューとビルドを継続する。
