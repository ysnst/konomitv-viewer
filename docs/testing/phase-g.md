# フェーズG 字幕シーク修正の検証

開始版0.19/build19、`6c0fd73e412cddd56a1681f1cac1c8367df74257`。同版のユーザー実機結果は[device-0.19.md](device-0.19.md)。成功16件、失敗0件、未確認1件だが、追加検証でHEVC字幕残留を発見した。

## ソース・自動検証と実機の境界

シーク開始で字幕画像を無効化し、最新の再生部品の完了から再構築する。取得済み字幕・管理情報をすべて捨てる方式や固定時間消去は使わない。通常/全画面は所有元の同じエンジン/表示ビューを使う。設定値は変更しない。

Foundationテストは取得済み範囲・表示候補packet・シーク世代を検証する。libaribcaptionの実描画、映像との同期、UIKit、LiveContainer、実サーバー通信の証明ではない。Python9件、履歴/ページ位置Swift、JPEG/EXIF、Pillow、actionlint、iOS ReleaseとIPA来歴を別途確認する。

HEVCでは成功完了したHTTP200 segmentだけを連続受信範囲に加える。未取得区間の消去イベントは不明なので、その穴より前の無期限字幕を推測で持ち越さない。移動先の字幕が未取得の直前segmentから続いている場合やAVPlayerの未知位置では、必要なデータが届くまで正確な復元を保証できない。全編取得や字幕の有効時間の捏造は行わない。
