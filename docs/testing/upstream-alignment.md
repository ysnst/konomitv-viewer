# 本家構造移植の実機チェックリスト

対象はintegration/upstream-syncで段階的に生成する未署名IPA。IPA 0.20の実機結果を新版の成功として流用しない。以下はすべて新版の実機未確認とする。第1段階は非同期開始、第2段階は再生寿命・シーク表示、第3段階は同じ画面での全画面切り替えを確認する。

## 開始・終了

- HEVC録画、H.264録画（素材の新規準備は不要）、生放送の開始・音声同期。
- Cloudflare Access経由の開始、開始待ちでの一時停止/再生、連打、画質変更、画面離脱。古い開始が復活しないこと。
- 中継が用意できない場合のエラーと再試行。認証必須時に直接接続しないこと。
- データ放送の開始、開始待ちの終了/再開始、リモコン、認証。
- 戻るジェスチャーの完了と取消、連続した番組切り替え、旧音声が残らないこと。

## シーク・再接続

- 開始前/再生中/一時停止中の短距離・長距離・前後・連続シーク。タップ/ドラッグ/スキップ/CM/リピート/履歴/コメント検索。
- 表示位置は目標へ追従し、実際の再生開始後は実時計へ戻ること。字幕・履歴・PiPは表示専用の目標位置を保存しないこと。
- 字幕あり→なし/別字幕/なし→あり、未取得区間、字幕ON/OFF。古い字幕の残留を再発させないこと。
- シーク後の字幕同期ずれが再発した場合は[フェーズH](phase-h.md)の確認事項を記録する。再現しなくても原因解消と断定しない。
- 通信切断・復帰、keepalive失敗時の回復とエラー、品質変更との競合。PiP中と終了後の回復、履歴更新。
- 録画10秒キャッシュの回線変動耐性、長時間再生の負荷/発熱/消費電力。

## 全画面・操作・PiP

- 通常/全画面の6操作（通常撮影、実況、字幕、設定、PiP、全画面）、中央5操作、時間表示。
- 回転、Safe Area、Dynamic Island、ホームインジケーター、戻る操作、通常画面への向き復元。
- 細い映像下端シーク、CM表示、シーク中だけの密度グラフ、自動非表示。
- 映像下の通常設定/右側の全画面設定とサブメニュー、設定中の全画面切り替え、音声のみ/速度/画質/おやすみ/再起動。
- 全画面前後の字幕・実況・BMLの位置と同期。番組情報/コメント下部タブとスクロール復帰。
- HEVC PiP開始・継続・復帰、全画面→PiP→一覧→PiP復帰、開始失敗、別番組開始。H.264/生放送のPiPは実装と実機確認を区別する。

## 維持する機能

- 通常/字幕付き撮影、通常/全画面、サーバー/写真/両方、PWA保存設定、JPEG/EXIF、操作UIと実況の混入防止。
- 写真/両方の保存は現行版で個別実機成功報告がなく、未確認のまま扱う。
- 録画ホーム10/4/4、検索/フィルター/並び順、9ボタン、スクロールON/OFF、一覧復帰、30秒更新。
- 視聴進捗・履歴双方向同期、保持件数の数値入力、PWA設定同期、接続先/認証/設定保持。

PiP内字幕/実況、L字クロップは今回の対象外。実況コメント付き撮影は削除済み。WindowsではiOS画面の起動・撮影ができないため、見た目・タッチ・回転の確認は実機で行う。
