# IPA 0.26以降の追加更新チェックリスト

基準は[0.26の実機成功9項目](device-0.26.md)。今回生成する段階A（テスト基盤のみ）と段階B（HEVC fMP4/復旧追加）は別の実機確認対象で、以下はすべて新版の実機未確認とする。[取り込み内容・ビルド記録](../upstream-next.md)の完全SHAと版番号を対応させて確認する。

段階Aは0.27 / build 27、段階Bの最新候補は0.29 / build 29。0.28と0.29のアプリコードは同じで、0.29はUI試験環境の調整後に生成したもの。どのIPAを試したかを必ず記録し、別版の成功を転記しない。

**品質確認は未完了**: [UIスモーク最終実行](https://github.com/ysnst/konomitv-viewer/actions/runs/45752116278)は、通常画面の時計が4秒で進まず失敗した。原因は未特定。これは実機で報告された不具合ではなく、字幕同期ずれとも別件である。映像をタップして操作帯を再表示した前後、全画面往復の前後で再生が継続するかを追加確認する。停止した場合は、時刻・操作・再生/停止アイコン・画面モードを記録する。全自動テスト成功とは扱わず、mainは0.26のまま維持する。

本家の新着`a2de08583aec2ea66c31ba9605acc84e394c5e15`（fMP4開始監視）は未取り込み。0.29では状態だけplayingになって位置が進まない場合に開始復旧が働かない制約がある。新着の監視・再試行の安全な接合を別段階へ保留し、既存のTS/VLC UI停止と混同しない。0.29のfMP4は安定版として推奨しない。

## 両段階の回帰

- HEVC録画の再生・前後シーク、短距離/長距離/連続/一時停止中、途中再生、CM/ダイジェスト/リピート/コメント検索からの移動。
- 通常/全画面の切り替えと復帰、回転、Safe Area、6操作の順序、下端シーク、操作中だけの密度グラフ、下部タブ。
- 通常/全画面の設定、画質/速度/コメント/字幕/音声のみ/タイマー/再起動。
- 字幕残留が再発しないこと、字幕・文字スーパー・実況の表示と同期、字幕ON/OFF。同期ずれが再発した場合は[フェーズH](phase-h.md)の条件を記録する。再現しなくても原因解消と断定しない。
- HEVC PiP開始・継続・復帰、全画面からの移行、アプリ離脱・復帰、履歴同期、開始失敗時の通常再生維持。
- 通常/字幕付き撮影、通常/全画面、UIと実況の混入防止、サーバー保存、Cloudflare Access、保存先/PWA設定。写真/両方保存は引き続き個別未確認であり、今回新たに確認する。
- 録画ホーム10/4/4、検索/絞り込み/並び順、9ボタン、自動スクロールON/OFFの上下操作、一覧復帰・30秒更新時の位置保持。
- 視聴履歴/進捗の双方向同期、保持件数入力、接続先・認証・設定保持、データ放送・既存番組操作。
- H.264/生放送の再生・PiPは実装と実機確認を区別する。H.264素材を新たに用意する必要はない。

## 段階Bで追加する確認

- 対応サーバーがHEVC要求のplaylistにEXT-X-MAPを返す場合のfMP4/AVPlayer開始。非対応サーバー・TS応答・probe失敗では従来VLC4へ戻ること。開始待ちの画質変更/停止/画面離脱/接続変更で古い要求が復活しないこと。
- fMP4の先頭/途中からの開始、開始前失敗→一度の待機再試行→VLC復帰。再試行中の停止/再生、最新seek、連打、手動再試行、中継失敗、バッファリング。
- fMP4の字幕・文字スーパーの受信、表示/消去、前後/連続seek後の内容と時刻、停止中・速度変更後の同期。映像成功だけで字幕も成功としない。
- fMP4の通常/字幕付き撮影、解像度・向き・色・映像との時刻、サーバー/写真/両方の各保存結果、操作UIの混入防止。既存TS/VLC経路と比較する。
- fMP4のPiP・音画同期・視聴位置同期、PiP開始待ち/有効中に項目が失敗した場合、画面復帰後の保留復旧、所有元を閉じた後の終了。復帰先の消失/二重再生/古い音声がないこと。
- 同じセッションでfMP4からTS/VLCへ戻れるサーバー契約、Cloudflare Access経由のinit/segment/seek、Range応答。一般的な標準サーバー互換性と、fMP4対応改造サーバーでの成功を分ける。
- 長時間のCPU/GPU/メモリ/発熱/消費電力/画質・フレームレート・ハードウェアデコード。ソース上の既存経路維持を性能実測へ読み替えない。

既存のTS fixtureでのシミュレーターテストは、実際のfMP4/emsg・字幕画像・HEVC撮影フレームやLiveContainerを証明しない。PiP内字幕/実況、L字クロップは今回対象外。実況コメント付き撮影は削除済みのままとする。mainの実機基準版0.26は、新版の実機確認とユーザー了承まで維持する。
